# Лейблы по реальной переписке «IT + СЕРВИС»

Пересмотрено 19.10.2026 после чтения production-таблицы `TelegramMessage`.
Выборка: 926 сообщений за 5–19 октября 2026, до 15:58 по Казахстану
19 октября. Это сообщения, включая ответы, склейки и напоминания, а не
926 отдельных обращений. Рассмотрены тексты обращений по платежам и переводам
и связанные уточнения. Изображения в этой проверке не просматривались.
Доступ к БД выполнялся в транзакциях READ ONLY; данные не менялись.

Первоначальный вариант был основан только на пакете знаний от 09.10,
а не на истории бота. Он заменён: отдельные категории ошибки пары ҰБТ,
предоплаты и общей ошибки продления не отражали основной поток новых запросов.
Исходный `commerce.md` по пути из пакета недоступен; правила пакета не
используются как доказательство частоты текущих обращений.

- [Уточнение целевой группы](https://t.me/c/3795755812/5007), [расшифровка 01/11/21/31 в месяцы](https://t.me/c/3795755812/4938): нужны месяц потока и группа либо явное «любой куратор».

- [Возврат после срока при более раннем выходе](https://t.me/c/3795755812/5021): нужна дата обращения/выхода, а не обязательная сумма уже выполненного возврата.

бизнес-правила или доказательство правильности названных ими сумм.

## Итоговая форма (20.10.2026)

Семь отдельных ярлыков черновика 19.10 сведены в **один ярлык «Жаңа төлемдер
бойынша»** (`new-payments`) в группе «IT + Сервис». Первое поле «Не керек?»
выбирает тип, остальные поля показываются по `showIf` от него. UI формы не
менялся. Дополнительный источник — разбор обращений 15–20.10 в чате с
дежурным (кейсы ниже) и ops-заметки juz40.

Всегда обязательны: тип, контакт ученика (номер или почта) и «"Оқушы"
формасында жасап көрдіңіз бе?». Если ответ «қате шықты», обязателен скрин
формы с ошибкой (Request ID длинный, руками его не перепечатают); текст
ошибки — по желанию. Ветки второго уровня зависят только от этих всегда
видимых полей: значения скрытых полей форма не стирает, и условие от поля
другой ветки оставило бы хвост прошлого выбора.

| Тип | Обязательные поля | Скрин |
|---|---|---|
| Кредит беру | сумма; основание (артық төлем / пән алынды / баға түзету / басқа) | нет |
| Кредитті алып тастау / азайту | сумма; сколько должно остаться | нет |
| Пән / ағым / тариф ауыстыру | қайдан; қайда (әр пәннің ағым айы); қай айдың төлемі; топ / куратор немесе «кез келген»; продление келесі айға; ескі айлар ашық па; ақшамен не болады (ештеңе / кредит / доплата / қайтарылмайды) | нет |
| Пәнді / продлениені алып тастау | қайдан; қай ай; ескі айлар ашық па; ақшамен не болады | нет |
| 0 ₸-ге қосу | пән / ағым; қай ай; топ; неге тегін (грант / туысы / бұрын төлеген / отбор / басқа); кім келісті | нет |
| Сілтеме сомасы басқа | пән / ағым; қай ай; ПФ қазір көрсеткен сома; керек сома; неге | да |
| Төленді, бірақ ашылмады | пән / ағым; қай ай; қанша, қашан төледі | да |
| Картаға қайтару | пән / ағым; қай ай; қанша, қашан төледі; қанша қайтару; себебі және шыққан күні | нет |
| Төлемді / кредитті тексеру | что проверить | нет |

Необязательно везде: сумма кредита/доплаты для перевода и снятия (дежурный
считает сам), дополнительный комментарий, скрин там, где он не обязателен.

Почему эти вопросы — каждый закрывает переспрос, который был в реальных
кейсах 15–20.10:

- **Месяц оплаты отдельно от названия потока**: «Физика қараша қосу» оказалось
  потоком ҚАРАША, а «МС ТЕХ қазанға» — потоком ҚАЗАН с окном қараша.
- **Ағым айы у каждого предмета**: SMART PRO → SMART «Гео шілде, Мат шілде,
  Тарих тамыз, Геом қазан».
- **Группа / куратор**: «Биология — Дана Муратова, Химия — Жанерке».
- **Деньги**: «кредит болмау керек», «без возврата, но 15 500 оставить
  кредитом», «кредит 9к на платформу, не на карту».
- **Старые месяцы**: «қалған айлар толық ашылып тұрсын» и «Тарих қыркүйек
  тобынан шығарамыз ба?».
- **Тегін и кто согласовал**: TOEFL по гранту, «Жұлдызай апайдың туысқаны».
- **Ошибка формы**: 500 с Request ID и «Шығармашылық пен басқа пәндер бір
  айда болмайды» — по скрину сразу понятно, нужен ли скрипт.

Прежние ярлыки `payment`, `catalog`, `discount`, `other` и смена номера/почты
сохранены. Обязательность проверяется одним справочником на клиенте и сервере
(`missingFields`). Тест: `npx tsx --test scripts/commerce-labels.test.ts`.
Форма собирает запрос, финансовые операции сама не выполняет.
