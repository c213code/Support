# DV-7952: доступ после теории недели

Подключённый пакет `weekly-theory-gate-v1` для локального агента Support.
Источник — предоставленный `DV-7952-full-documentation.md` и сверенные фрагменты
локального backend JUZ40. Исходная кодовая база не изменяется. Подготовлен
12.10.2026, Asia/Almaty. Коммит и SHA-256 источников находятся в `sources.json`.

11 правил покрывают обязательную теорию недели, групповой итоговый SUCCESS,
настройки курса, прямой доступ, персональные/кураторские задания, флаги списков,
кеш, стрик/календарь, дедлайн лекции, порог просмотра и конфликт finishTime.
Есть примеры обращений RU/KZ и 8 SELECT-шаблонов, включая проверки схемы.
SQL запускает дежурный вручную. DataGrip bridge недоступен при подготовке:
живая схема и версия production не подтверждены.

## Что требует отдельной проверки

- Документ обещает finishTime первого завершения видео. В прочитанном
  `updateProgressVideoTiming` есть переход videoViewed/SUCCESS, но нет записи
  finishTime; `ProgressService.save` также её не добавляет. Условие gate проверяет
  SUCCESS, поэтому отсутствие времени само по себе не доказывает причину замка.
- Backfill 002 задаёт четыре закрываемых типа, текущие дефолты курса — пять,
  дополнительно PRAKTIKALYK_SABAK. Проверяется конкретная настройка курса.
- Документ описывает фронтенд, но в этом пакете сверялся backend. Нельзя считать
  модалку, перечитывание списков и поведение всех клиентов подтверждёнными.
- Старый кеш цели может показывать false. False не доказывает открытый доступ.

## Подключение

`routing.enabled=true`. Отбор по DV-7952, weeklyTheoryLocked, сообщению замка,
теории недели и новым дедлайнам лекций. Просто «квиз не открывается», «403»,
«видео зависло», «дедлайн урока прошёл» этот пакет не запускают.
Стрик с weeklyTheoryLocked может подключить два пакета; их правила не подменяют
друг друга. К фото добавляется подпись с действием/фичей.

Worker перечитывает пакет при следующем опросе; перезапуск не нужен.
В рабочую папку кейса попадают правила, инструкции, SELECT, исходный документ
как справочный материал и ограниченные фрагменты относящегося backend.
Список фич на сайте обновляется после деплоя.
