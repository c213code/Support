# Контрольные кейсы DV-7952

Синтетические примеры: без реальных учеников, не подтверждение production.

| Обращение | Правила и ожидаемый разбор |
| --- | --- |
| «Теорию недели посмотрел, ОСТ не открывается» | WTG-001/002/004: полный набор обязательных лекций, SUCCESS total этой группы, точная ошибка. По слову «посмотрел» причину не устанавливать. |
| «Теорияны бітірдім, ОСТ ашылмай тұр» | То же на казахском. При подтверждённом незавершённом уроке объяснить: «Осы аптадағы барлық міндетті теориялық сабақтарды аяқтау қажет». Без результата проверки — условный черновик. |
| «По первой лекции SUCCESS, по второй IN_REVIEW» | WTG-002: для gate нужна каждая лекция в SUCCESS; правило зачёта IN_REVIEW в стрике сюда не переносить. |
| «Теория нерейтинговая, почему требует её?» | WTG-001: is_rating не исключает обязательную общую лекционную теорию. |
| «После перевода в группу теория SUCCESS в старой группе» | WTG-002: в предикате совпадает group_id, перенос не обещать; Q03/Q07. Коммерцию применять только при явном кейсе перевода. |
| «Практика закрылась, у другого курса открыта» | WTG-003: конкретный массив целей; backfill не содержит PRAKTIKALYK_SABAK, текущие дефолты содержат. |
| «Персональное задание с замком другой недели» | WTG-005: проверить общую/персональную/кураторскую тему и month/week, а не название. |
| «weeklyTheoryLocked=false, прямой запрос даёт отказ» | WTG-004/006: false не гарантирует доступ; точный ответ, старые ограничения и кеш. |
| «Стрик: задание weeklyTheoryLocked и осталось в цели» | WTG-008 и daily-streak-v1: флаг не исключает задание из нормы. |
| «Все теории SUCCESS в этой группе, замок после обновления остался» | WTG-007: Q04, свежие ответы списка/деталей, время; кеш — гипотеза. Подтверждённое несоответствие — разработчику. |
| «Лекция: withDeadline=true, ошибка deadline_is_null» | WTG-009: нужен payload и дата; не выключать дедлайн автоматически. |
| «Лекция просмотрена 60%, почему уже SUCCESS?» | WTG-010: локальный порог 50%; проверка версии перед утверждением production-порога. |
| «Дедлайн лекции: SUCCESS есть, finishTime пустой» | WTG-011: документ/код расходятся; время не условие gate, зачёт в стрике отдельно. |
| «Обычный квиз не открывается / видео зависло» | Нет признаков DV-7952: пропустить этот пакет. |
