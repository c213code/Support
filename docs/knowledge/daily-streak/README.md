# Daily Streak / «Менің Жұлдызым»

Подключённый пакет `daily-streak-v1` для локального агента Support. Основной сайт JUZ40
используется только как источник кода и не изменяется.

Источники: присланное объявление, шестистраничный `Daily-Streak-business-logic-kk.pdf`,
локальный backend `master` на `445fd9c59df3305af8cdb475b987a136a4b13123`, его миграции
и заметки `docs/structure/modules/streak`. Дата подготовки: 2026-10-12, Asia/Almaty.
Документ заявляет preprod + Figma v6; локальный код может быть новее. Manifest содержит
хеши прочитанных файлов. Версия production и живая схема не подтверждены.

13 правил покрывают нормы уроков, две части 30%, ҰБТ, отдых, воскресенье, статусы,
пул доступных заданий, снимок закрытого дня, сброс и восстановление куратором.
Для диагностики — 7 SELECT-шаблонов с предварительной проверкой схемы; их запускает
дежурный вручную. Пустая или ограниченная выборка не является доказательством причины.

## Расхождения, которые агент обязан учитывать

1. PDF стр.3: воскресенье — все просроченные уроки. Локальный DV-8305:
   `min(D,max(4,ceil(0.3*D)))`, после проверки сегодняшних дедлайнов. Без долга
   открытый ҰБТ всё равно исключает REST. Нужна проверка версии/ответа API.
2. Локальный Variant A требует обе части нормы независимо. Избыток просроченных
   не закрывает «Остальные», вопреки старому комментарию OpenLessonsQuota.
3. В PDF пять визуальных состояний, в коде дополнительно REST/DANGER; ноль
   различается NEW/AFTER_LOSS. Клиент должен использовать ответ backend.
4. PDF говорит о кураторе именно группы ученика. Прочитанный handler проверяет
   роль CURATOR и членство ученика; отдельный ownership-контроль не подтверждён.
5. Журнал восстановления хранит длину цепочки до разрыва, а ответ операции — всю
   восстановленную цепочку. Пример 14 + пропуск 6 + закрыто 3 → 17.

## Подключение

`routing.enabled=true` и специфичные RU/KZ/EN фразы отбирают вопросы о стрике,
«Менің Жұлдызым» и счётчике цели. Общие слова «ҰБТ», «квиз», «урок», «просрочено»,
«жексенбі» сами по себе не запускают этот пакет. Добавляйте к фото подпись с фичей.
Worker перечитывает пакет при следующем опросе; сайт получает его после деплоя.
