# Контрольные кейсы для поддержки

Это синтетические примеры, не реальные ученики и не доказанные production-инциденты.

| Обращение | Правило и ожидаемое объяснение |
| --- | --- |
| «Стрик: сделал три просроченных, цель 3, но не закрылась» | DST-003: при цели 2 просроченных + 1 остальной локальный progress остаётся 2/3. Запросить обе части dailyGoal, не объявлять баг без ответа API. |
| «Менің Жұлдызым: уроки 0/4, звезда прибавилась после ҰБТ» | DST-004: FINISHED ҰБТ может закрыть день параллельно урокам. Проверить unts и журнал, не требовать обе ветки. |
| «Стрик: жексенбі, долга нет, а отдых не включился» | DST-006: сначала сегодняшние дедлайны и открытые ҰБТ. Отсутствие только просроченных недостаточно. |
| «Daily Streak: инструкция требует весь воскресный долг, экран — 4» | DST-006: конфликт PDF/DV-8305. Проверить версию и API, не называть экран ошибкой. |
| «Стрик: задание IN_REVIEW, ждать проверки?» | DST-007: отправка на проверку может засчитаться при total-result и finish_time в текущем дне; Q05 даёт evidence. |
| «Стрик: после восстановления серые дни не стали жёлтыми» | DST-012: MISSED остаётся MISSED, снимается разрыв. Долг и totalActiveDays не списываются/не растут. |
| «Стрик: было 14, болел 6, потом 3 дня; вернулось 17» | DST-012: объединяются обе части закрытой цепочки. Не прибавлять 6 пропусков. |
| «Стрик: кнопка восстановления серая» | DST-010/011: canWaiveReason, конец последнего разрыва и окно 14 дней, прежний waiver, роль и группа. |
| «Стрик: админ получает 403» | DST-011: локальный маршрут только CURATOR; нужен точный ответ/роль. Не предлагать обход. |
| «Менің Жұлдызым: 0 у новичка» | DST-009: NEW при totalActiveDays=0, без утверждения о потерянной серии. |
| «Квиз не открывается, материалы IELTS не грузятся» | Нет признаков подключённой фичи: пропустить, не создавать Daily Streak подсказку. |
